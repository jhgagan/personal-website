# Gagan J H — Personal Portfolio

Personal portfolio website for Gagan Jattenahalli Harishkumar, Telecommunication Engineering M.Sc. student at Politecnico di Milano.

## Overview

A single-page portfolio built with vanilla HTML, CSS, and JavaScript. Features include:

- **Hero section** — intro and quick-navigation links
- **Skills** — language and framework logos (Assembly, Bash, C++, Dart, Flutter, gRPC, HTML, Java, JavaScript, LaTeX, LTspice, Node-RED, Python, R, React, TypeScript)
- **Experience & Education** — professional timeline and academic background
- **Projects** — featured work with modal detail views
- **Publications** — linked academic papers
- **Contact** — email, GitHub, LinkedIn, Google Scholar links
- **Dark mode** — respects system preference, persists via `localStorage`

## Structure

```
personal-site/
├── index.html       # Single-page app
├── styles.css       # All styles (light + dark theme)
└── images/          # Skill logos and headshot (WebP)
```
