Design and Performance Evaluation of a UAV Radar Imaging System

Modeled a UAV radar system to analyze target detection at varying ground ranges. I performed theoretical derivations for antenna gain and power requirements and used MATLAB to simulate the transmission and reception of Linear Frequency Modulation chirp signals. By implementing matched filtering for range compression, achieved significant signal processing gain, effectively isolating target energy from thermal noise.

Design and Performance Evaluation of a UAV Radar Imaging System

This project focused on developing a Synthetic Aperture Radar (SAR) imaging system for UAV platforms. The project involved processing recorded radar echoes using range compression and implementation of the Time Domain Back-Projection (TDBP) algorithm to generate high-resolution environmental images. It also involved noise filtering and performance evaluation.

Cháksu: A Glaucoma-specific Fundus Image Database

Developed and curated the Chákṣu retinal fundus image database containing 1,345 expertly annotated images for glaucoma prescreening research. The dataset includes optic disc and optic cup segmentations, glaucoma assessments from five ophthalmologists, and fused ground-truth annotations using methods such as STAPLE. Chákṣu serves as one of the largest Indian-ethnicity-specific retinal imaging datasets to support AI-driven glaucoma diagnosis and computer-assisted ophthalmic analysis.

Journal: Scientific Data (Nature)

DOI: 10.1038/s41597-023-01943-4

Automated Optic Disc Segmentation Using Basis Splines-Based Active Contour

Developed a fully automated optic disc segmentation framework for retinal fundus images using a basis-spline active contour model optimized through gradient descent and Green's theorem. The method enables efficient and accurate segmentation with reduced computational complexity and was validated on 2,993 retinal images across the Drishti-GS, MESSIDOR, RIGA, and local datasets, achieving strong Dice similarity scores across all benchmarks.

Journal: IEEE Access

DOI: 10.1109/ACCESS.2022.3199347
