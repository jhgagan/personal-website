Semantic Communication Simulation with Sionna

Master's Thesis — Politecnico di Milano

Designed and implemented a modular simulation framework for semantic communications using Nvidia's Sionna physical-layer wireless simulation library. The system demonstrates Feature Identification-based semantic encoding, where only task-relevant features of the source data are transmitted rather than raw bits.

Key contributions:

  • Architected a multi-process pipeline using gRPC for inter-process communication, decoupling the semantic encoder, channel simulator, and semantic decoder into independently scalable modules.
  • Leveraged Sionna to model end-to-end physical-layer effects including AWGN and fading channels, enabling realistic BER vs. SNR analysis for semantic payloads.
  • Evaluated semantic reconstruction quality against classical bit-level transmission across varying channel conditions.

Technologies: Python, TensorFlow, Sionna, gRPC, Protocol Buffers

Internet of Things

A series of three lab challenges covering IoT protocol analysis, data pipeline development, and wireless sensor network programming.

Challenge 1 — CoAP Protocol Analysis

Parsed and analysed Constrained Application Protocol (CoAP) network traffic from live packet captures (.pcap / .pcapng). Used Python's Scapy library with a custom CoAP dissector layer (RFC 7252) to extract message IDs, request codes (GET, POST), response codes (2.05 Content, 4.04 Not Found), and URI options from UDP port 5683 traffic.

Challenge 2 — Node-RED MQTT Pipeline

Built a data processing flow in Node-RED to ingest and filter MQTT messages. Implemented a JavaScript function node that parses incoming Publish Message payloads, splits batched JSON records, and attaches timestamps and unique message IDs before forwarding downstream. The flow handles single and multi-record payloads and filters non-publish traffic.

Challenge 3 — TinyOS Radio Routing on WSN

Implemented a dynamic routing protocol in TinyOS/nesC for a 7-node wireless sensor network. The protocol exchanges three message types — ROUTE_REQUEST (broadcast), ROUTE_REPLY (broadcast with cost), and DATA_PACKET (unicast) — to build and maintain per-node routing tables. Simulated the topology using TOSSIM on MicaZ and TelosB platforms with a realistic Meyer-Heavy noise model, and verified end-to-end packet delivery from node 1 to node 7.

Technologies: Python, Scapy, Node-RED, JavaScript, TinyOS, nesC, TOSSIM

Geophysical Imaging

Two assignments exploring signal processing methods for subsurface imaging, completed as part of the Geophysical Imaging course at Politecnico di Milano.

Assignment 1 — Fundamentals of Seismic Imaging

Analysed seismic data acquisition geometry, including shot-receiver configurations and common midpoint (CMP) sorting. Applied Normal Moveout (NMO) correction to flatten hyperbolic reflection events and performed velocity analysis to estimate subsurface acoustic properties.

Assignment 2 — Migration and Imaging Algorithms

Implemented and compared seismic migration algorithms to collapse diffraction hyperbolas and correctly position reflectors. Studied the effect of migration aperture and velocity model accuracy on image resolution, and evaluated trade-offs between computational cost and imaging fidelity.

Technologies: MATLAB, Signal Processing, Seismic Data Analysis

Design and Performance Evaluation of a UAV Radar Imaging System

Modelled and evaluated the performance of a UAV-mounted pulse radar system for ground target detection at varying ranges.

Key contributions:

  • Derived theoretical antenna gain requirements and transmitted power budgets using the Radar Range Equation to satisfy a target detection SNR at multiple ground ranges.
  • Designed a Linear Frequency Modulation (LFM / chirp) waveform and simulated its transmission, propagation, and reception in MATLAB.
  • Applied matched filtering (pulse compression) to the received echoes, achieving substantial processing gain that separates target returns from thermal noise.
  • Analysed range resolution, range ambiguity, and Doppler tolerance as a function of bandwidth and pulse duration.

Technologies: MATLAB, Radar Systems Engineering, Signal Processing

Design and Performance Evaluation of a Synthetic Aperture Radar System

Developed a complete SAR image formation pipeline for a UAV-mounted radar, processing raw recorded radar echoes into focused, high-resolution ground images.

Key contributions:

  • Performed range compression on received echoes using matched filtering of the LFM chirp waveform to achieve fine range resolution.
  • Implemented the Time Domain Back-Projection (TDBP) algorithm to coherently integrate slow-time aperture samples, correctly focusing point scatterers and extended targets in the along-track dimension.
  • Applied noise filtering techniques to suppress sidelobes and clutter, and evaluated image quality through metrics such as Impulse Response Width and Peak Sidelobe Ratio (PSLR).
  • Compared TDBP imaging performance against theoretical resolution limits derived from aperture length and wavelength.

Technologies: MATLAB, SAR Signal Processing, Radar Imaging

Bluetooth-LE 6.0 Distance Estimation

Benchmarked Bluetooth Low Energy 6.0 ranging techniques against Ultra-Wideband (UWB) and deployed a TinyML model on embedded hardware for on-device distance estimation.

Techniques evaluated:

  • RSSI (Received Signal Strength Indication): Baseline path-loss model; high variance in multipath environments.
  • PBR (Phase-Based Ranging): BLE 6.0 Channel Sounding; sub-metre accuracy in line-of-sight conditions.
  • RTT (Round-Trip Time): BLE 6.0 two-way time-of-flight; improved robustness over RSSI.
  • UWB DS-TWR (Double-Sided Two-Way Ranging): Reference technology; centimetre-level accuracy with clock-drift cancellation.

Edge AI deployment: Collected a labelled range measurement dataset using the Nordic nRF54L15 Development Kit and trained a compact neural network. The quantised model was deployed on-device via TinyML to perform real-time distance inference directly on the microcontroller, eliminating cloud round-trips.

Technologies: BLE 6.0, UWB, Nordic nRF54L15, TinyML, Python, Embedded C

Autonomous Vehicle Sensor Fusion — EESTEC Engineering Challenge 2026

Team Secure Motion — Politecnico di Milano  |  1st Place

Developed a real-time multi-sensor fusion pipeline to track an opponent race car relative to an ego vehicle during a race at Yas Marina Circuit. The system fuses LiDAR, radar, and camera data through an Extended Kalman Filter to produce stable state estimates of range, relative heading, absolute velocity, and uncertainty bounds.

Dataset: 120 seconds of racing data from PoliMove — 2,388 synchronized frames from 7 cameras, 3 LiDARs, and 4 radars stored in a ROS2 SQLite3 bag.

Key contributions:

  • Parsed CDR-serialized ROS2 bag data and synchronized multi-rate sensor clocks across 14 active topics.
  • Implemented PointCloud2 blob decoding with bounding-box filtering and 20th-percentile forward depth for precise LiDAR range extraction.
  • Decoded radar Doppler returns for direct radial velocity measurements and cross-sensor consistency.
  • Deployed YOLOv8 for camera-based object detection with a low-floor confidence cascade to handle formula car appearances absent from the training set.
  • Built a 2D world-frame Extended Kalman Filter with asynchronous sensor update models for LiDAR range, radar position, and radar radial velocity, integrated with ego vehicle kinematics from GPS/IMU dead reckoning.
  • Achieved ~0.3 m positional variance and ~0.2 m/s velocity variance across the full 120-second run.
  • Built a 4-panel real-time dashboard: 7-camera mosaic with YOLOv8 overlays, bird's-eye LiDAR view, radar scatter map, and HUD telemetry strip.

Team: Gagan J H · Ashkriti Dewan · Hardik Nayak

Technologies: Python, ROS2, YOLOv8, Extended Kalman Filter, PointCloud2, Radar CDR Decoding, MATLAB, NumPy, OpenCV, Matplotlib
